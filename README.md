# Молодая наука — 2026

Адаптивный лендинг научно-практической конференции имени А. В. Новикова, НГУЭУ. **Учебный проект. Неофициальный сайт конференции.**

React 19, Vite 7, обычный CSS. Сервер приложения, база данных, ключи API и платные сервисы не нужны. Иллюстрация создана CSS, фотографии не используются. Шрифт Manrope загружается из Google Fonts; при недоступности используется системный Arial.

## Локальный запуск

Нужен Node.js 24 LTS и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, с путём `/molodaya-nauka-2026/` (обычно порт 5173).

```bash
npm run build
npm run preview
```

Сборка находится в `dist/`. Preview позволяет проверить готовую сборку (обычно порт 4173). Не открывайте `dist/index.html` напрямую как файл.

## GitHub Pages

1. Отправьте файлы в ветку `main` репозитория `RRRondddd/molodaya-nauka-2026`.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. В **Actions** дождитесь успешного workflow `Deploy to GitHub Pages`. Его также можно запустить вручную через **Run workflow**.
4. Адрес после успешной публикации: `https://rrrondddd.github.io/molodaya-nauka-2026/`.

Workflow `.github/workflows/deploy.yml` выполняет `npm ci`, сборку и публикацию `dist`. Путь `/molodaya-nauka-2026/` настроен в `vite.config.js`; при переименовании репозитория измените `base`. Публикация требует доступных GitHub Actions и Pages в настройках репозитория. Из среды разработки публикация не выполнялась.

## Где менять информацию

- `src/main.jsx` — все тексты, массивы `sections` (секции), `faq`, подсказки `prompts`, правила ответов `answer` и компоненты.
- `src/styles.css` — оформление, мобильные размеры, анимация и режим уменьшенного движения.
- `index.html` — название вкладки и метаданные.
- `vite.config.js` — путь публикации.

Помощник — локальный интерактивный прототип с предопределёнными ответами по ключевым словам, без генеративной модели и внешнего API. Он не регистрирует участников, не сохраняет переписку после перезагрузки и может не распознать переформулированный вопрос. Неизвестные сведения предлагает уточнять у преподавателя.

## Что проверить перед публикацией

- Подтвердите название, даты, руководителей, сроки регистрации и предварительную программу у организаторов.
- Передайте подтверждённую ссылку на сообщество кафедры: пока в подвале стоит пояснение вместо выдуманной ссылки.
- При получении подтверждённых аудиторий, контактов и правил обновите тексты и ответы помощника одновременно.
- Проверьте мобильную версию, навигацию клавиатурой, три вкладки, FAQ и чат. Убедитесь, что после публикации CSS и JS загружаются с пути репозитория.
