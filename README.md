# Young Science 2026

Учебный сайт для магистерской РГР. Неофициальный сайт конференции НГУЭУ.
React + Vite, локальный помощник и система заявок в браузере. Реальная регистрация
студентов и отправка преподавателям не осуществляются. Только вымышленные данные.

## Запуск

Node.js 24 LTS:

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview -- --port 4192
```

Путь `/molodaya-nauka-2026/` задан в vite.config.js. Дизайн: full-width фоны,
внутренние контейнеры, Manrope для заголовков и Onest для текста, кнопок и форм (Google Fonts
с системными резервами), синий, светлые и тёмные блоки, reduced motion.

## Заявки

Форма полностью активна. Пять обязательных полей: ФИО, email, руководитель,
секция, «Тема вашего исследования». После проверки запись получает UUID,
время и статус «Новая», сохраняется в localStorage. Только после успешной записи
показывается модальное подтверждение, форма очищается.

Отдельная демонстрационная страница `manage.html` фильтрует локальный список по выбранному
преподавателю. Статусы можно менять: Новая, На рассмотрении, Согласована,
Отклонена. Изменения и записи остаются после обновления в том же браузере.
Есть подтверждаемое удаление учебных записей, защита от совпадающих заявок,
обработка недоступного/переполненного/повреждённого хранилища.

Нет сервера, Google Sheets, внешнего API, авторизации или разграничения доступа.
Фильтрация — только учебная модель. Данные не синхронизируются между устройствами;
любой пользователь этого браузерного профиля может их увидеть. Не вводить реальные
персональные данные. Для демонстрации использовать одну вкладку. Очистка данных
браузера удалит записи. Подробности и сценарий защиты: [docs/applications.md](docs/applications.md).

## Файлы

- src/main.jsx — навигация, секции, программа, FAQ и чат.
- src/ApplicationForm.jsx — форма, ошибки, модальное окно.
- src/ApplicationsPanel.jsx — локальные таблицы и статусы.
- src/manage.jsx, manage.html — отдельная страница управления.
- src/useStickyHeader.js — измерение закреплённой шапки для якорей.
- src/application.js — валидация, хранение, защита от повторов.
- src/application-config.js — подтверждённые пользователем преподаватели.
- src/conference.js — данные конференции и FAQ.
- src/assistant.js — рекомендации секций по словарю синонимов, без генеративного ИИ.
- src/styles.css — оформление и адаптивность.

Помощник распознаёт основы слов, сокращения и синонимы; неоднозначные темы просит
уточнять, неизвестные не распределяет случайно. Не понимает сложный контекст,
отрицания и опечатки надёжно; не является генеративной моделью.

## Проверки

```bash
npm test
npx playwright install chromium
# При запущенном preview на 4192:
TEST_URL=http://localhost:4192/molodaya-nauka-2026/ npm run test:mobile
TEST_URL=http://localhost:4192/molodaya-nauka-2026/ npm run test:form
```

Для установленного Chromium добавить `CHROMIUM_PATH=/usr/bin/chromium`.
Проверяются 320/375/768/1440/1920 px, full-width фоны, отсутствие переполнения,
меню, секции, FAQ, чат, обязательные поля, клавиатура, локальное сохранение,
распределение, статусы, перезагрузка, дубликаты, ошибка записи и отсутствие POST.

## Демонстрационная страница преподавателей

Адрес: https://rrrondddd.github.io/molodaya-nauka-2026/manage.html.
Локально — тот же base path с `manage.html` в конце. В обычном меню и на главной
странице ссылки и таблиц нет. Страница доступна по прямому адресу, имеет
`noindex, nofollow`, но это НЕ авторизация и НЕ защита доступа. Не хранить реальные
персональные данные. Обе страницы используют один origin и один ключ localStorage.
`manage.html` можно перезагружать и открывать напрямую: Vite собирает два HTML-входа,
поэтому не требуется SPA fallback или изменение настроек Pages.

Шапка закреплена сверху. ResizeObserver обновляет отступ якорей под фактическую
высоту шапки. Мобильное меню раскрывается поверх контента, не сдвигая страницу.
Браузерные тесты дополнительно проверяют sticky-позицию, свободный от шапки якорь,
отсутствие таблиц на главной и весь сценарий перехода на manage.html и обратно.
