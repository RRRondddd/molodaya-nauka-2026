# Молодая наука — 2026

React + Vite, существующий лендинг НГУЭУ. Учебный проект. Неофициальный сайт конференции.

## Запуск и публикация

Node.js 24 LTS:

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview -- --port 4180
```

Путь сайта — `/molodaya-nauka-2026/`. GitHub: Settings → Pages → Source →
GitHub Actions. Merge в `main` запускает `.github/workflows/deploy.yml`: тесты,
сборка, публикация dist. Адрес: https://rrrondddd.github.io/molodaya-nauka-2026/.
При переименовании репозитория изменить base в vite.config.js.

## Дизайн

Deep Navy #09142D, Cobalt #285CFF, Electric Blue #438BFF, Icy Cyan #A3E6FF,
Off-white #F4F7FF. Тёмный hero с орбитальной CSS-графикой, светлые блоки
«О конференции» и FAQ, контрастная программа, светлый акцентный блок участия с двухколоночной формой.
Space Grotesk для заголовков, Onest для текста и интерфейса (Google Fonts);
для кириллицы, отсутствующей в Space Grotesk, используется Onest;
системный Arial при отсутствии доступа к веб-шрифтам. Поддерживается reduced motion.

## Что редактировать

- src/main.jsx — страницы, меню, переключение секций и чат.
- src/styles.css — оформление и адаптивность.
- src/conference.js — подтверждённые сведения и FAQ.
- src/assistant.js — локальная рекомендация секций по словарю синонимов.
- src/application-config.js — шесть преподавателей из программы, подтверждённых
  пользователем; настройки подключения (только публичные, без секретов).
- src/ApplicationForm.jsx, src/application.js — форма, валидация, подтверждение.
- server/Code.gs — маршрутизация в отдельные закрытые Google Sheets.
- server/gateway.mjs — Node.js gateway, без внешних зависимостей.

## Регистрация пока закрыта

Публичный интерфейс показывает «Приём заявок онлайн скоро откроется».
Поля и кнопка заблокированы. Реальные данные не принимаются и не отправляются.
Внутренняя конфигурация остаётся demo=true, approved=false, endpoint пустой.
Для включения нужны защищённый backend, утверждённые условия обработки данных,
consentUrl, consentVersion, маршруты и права Google Drive. Ни таблицы, ни
обработчики автоматически не развёрнуты. На реальных Sheets проверка не выполнена.
Подробная инструкция: [docs/applications.md](docs/applications.md).

## Проверки браузером

```bash
npx playwright install chromium
# При запущенном preview на 4180:
TEST_URL=http://localhost:4180/molodaya-nauka-2026/ npm run test:mobile
# Для формы также запустить dev-сервер:
npm run dev -- --port 4181
TEST_URL=http://localhost:4180/molodaya-nauka-2026/ npm run test:form
```

Для системного браузера добавить `CHROMIUM_PATH=/usr/bin/chromium`.
Проверяются ширины 320/375/768/1440/1920, меню, вкладки, чат,
переполнение, закрытая регистрация без сети. Локальная fixture (не входит в dist)
проверяет активную форму с синтетическими данными и подставными ответами сервера:
ошибки, валидацию, согласие, подтверждение, модальное окно и клавиатуру.
Модульные тесты Google выполняются на заглушках сервисов. Это не проверка
реального хранения и реальных прав доступа.

Помощник не использует генеративный ИИ и API. Сопоставляет основы слов, сокращения
и фразы; каждое понятие учитывается один раз. Близкие результаты требуют уточнения,
неизвестные темы не получают случайную секцию. Опечатки, отрицания и темы вне
словаря могут распознаваться неверно. Контекст сообщений не объединяется.


## Компоновка и скриншоты

`header`, `footer`, `main` и фоны секций не ограничены max-width. Только внутренний
`.container` имеет предел 1550 px и согласованные адаптивные отступы. CSS переписан
на единую систему без слоёв старых переопределений. Hero — асимметричная сетка с
орбитальным инструментом; программа — вертикальный список дат и соседняя панель;
участие — пошаговое пояснение слева и форма справа. На телефоне элементы
перестраиваются в одну колонку; у программы остаются три компактных вкладки.
